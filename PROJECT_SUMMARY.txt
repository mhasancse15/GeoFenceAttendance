🎯 USER WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Launch App
     └─ Request Location Permission

  2. Set Office Location
     └─ Fetch GPS coordinates and save locally

  3. Real-time Tracking
     └─ Continuous location updates every 3 seconds

  4. Distance Calculation
     └─ Calculate distance to office (Vincenty formula)

  5. Range Validation
     └─ Check if within 50-meter radius

  6. Visual Feedback
     └─ Display animated ring + IN/OUT OF RANGE status

  7. Time Window Check
     └─ Validate current time is 09:00-10:30

  8. Mark Attendance
     └─ Submit attendance (only when all conditions met)

📋 CODE ORGANIZATION PRINCIPLES

  ✓ Separation of Concerns
    - Data layer handles external APIs
    - ViewModel manages state
    - UI only displays and captures events

  ✓ Single Responsibility
    - Each class has one reason to change
    - Files organized by feature/layer

  ✓ Dependency Inversion
    - Repositories injected via factory
    - Dependencies passed via constructor

  ✓ DRY (Don't Repeat Yourself)
    - Utility functions for common calculations
    - Reusable composables

  ✓ Reactive Programming
    - Observable flows instead of callbacks
    - State-driven UI updates

  ✓ Immutability
    - Data classes for state
    - Coroutine-safe state management
